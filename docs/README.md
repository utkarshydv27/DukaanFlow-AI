# DukaanFlow AI Website

Responsive static landing page and illustrative browser-side message classifier.

## Files
- `index.html` — landing page and demo UI
- `styles.css` — responsive styles
- `script.js` — simple illustrative client-side classifier

## Demo limitations
The sample classifier uses browser-side rules only. It does **not** call the Flask backend, SQLite, Ollama, Qwen, or WhatsApp. Dashboard cards are illustrative; no real customer data is connected. Do not describe this static website as a live AI integration.

## Enable GitHub Pages
In the repository, open **Settings → Pages**. Choose **Deploy from a branch**, select `main` and `/docs`, then save. GitHub Pages will publish the contents of this directory when deployment completes.
